Detailed Description

Maintains joint anchor positions for child objects during scaling operations (v2).

Named after Hank Pym (Ant-Man), this improved version handles multiple joints per child.

The physics system calculates anchors at start but doesn't update them during scaling, causing models to fall apart. This script saves and reapplies anchor positions.

Requires a MolScale component on the same GameObject.
