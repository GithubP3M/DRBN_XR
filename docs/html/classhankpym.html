Detailed Description

Maintains joint anchor positions for child objects during scaling operations.

Named after Hank Pym (Ant-Man) because of it's ability to change size at will, this script handles the physics joint corrections needed when scaling objects. Automatically disables when max scale is reached. Requires a MolScale component on the same GameObject.

Allows to insert big molecules in versy small space
