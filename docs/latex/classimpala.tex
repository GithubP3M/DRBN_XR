\doxysubsection{Detailed Description}
Implicit Membrane Potential for Lipid Assembly (IMPALA) simulation. Applies position-\/dependent forces to simulate membrane insertion and hydrophobic interactions. 

Attach this script to a trigger collider representing the membrane region. Objects tagged "{}helix"{} receive membrane-\/specific viscosity and hydrophobic forces. Child transforms tagged "{}hydrophobic"{} receive additional insertion forces.
