\doxysubsection{Detailed Description}
Maintains joint anchor positions for child objects during scaling operations. 

Named after Hank Pym (Ant-\/\+Man) because of it\textquotesingle{}s ability to change size at will, this script handles the physics joint corrections needed when scaling objects. Automatically disables when max scale is reached. Requires a \doxylink{class_mol_scale}{Mol\+Scale} component on the same Game\+Object.
