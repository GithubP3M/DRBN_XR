\doxysubsection{Detailed Description}
Handles spawning of molecule prefabs into the simulation. Instantiates molecules at a designated spawn point and registers them with the physics system. 

Requires a \doxylink{class_langevin__v2}{Langevin\+\_\+v2} component on a Game\+Object tagged "{}\+Physics\+\_\+\+Sim"{}. Spawning is limited by molcounter.\+limit.
