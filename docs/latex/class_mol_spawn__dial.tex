\doxysubsection{Detailed Description}
Manages molecule spawning through UI dial interactions. 

Spawns molecule prefabs at a designated spawn point, tracks molecule counts, and registers spawned objects with the \doxylink{class_langevin}{Langevin} physics simulation.
