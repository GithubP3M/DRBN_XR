\doxysubsection{Detailed Description}
Implements a \doxylink{class_langevin}{Langevin} thermostat for molecular dynamics simulation. Applies stochastic and friction forces to all Rigidbody objects in the scene. 

Keyboard controls:\+
\begin{DoxyItemize}
\item O:\+ Unfreeze all objects (disable is\+Kinematic)
\item P:\+ Freeze all objects (enable is\+Kinematic)
\item I:\+ Toggle between normal and 30x time scale
\item \+[+]\+:\+ Increase temperature by 100K
\item \+[-\/]\+:\+ Decrease temperature by 100K 
\end{DoxyItemize}
