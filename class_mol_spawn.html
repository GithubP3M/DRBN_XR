Detailed Description

Handles spawning of molecule prefabs into the simulation. Instantiates molecules at a designated spawn point and registers them with the physics system.

Requires a Langevin_v2 component on a GameObject tagged "Physics_Sim". Spawning is limited by molcounter.limit.

void MolSpawn::SpawnMolecule ( )

Spawns a new molecule instance at the spawn point. Registers the molecule's Rigidbodies with the Langevin physics system and adds it to the molecule counter.

Only spawns if current molecule count is below molcounter.limit. Called from UI buttons.
